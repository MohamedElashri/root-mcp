# ROOT-MCP Docs

This directory contains the Sphinx documentation source. The main entry point
is `index.rst`; the Markdown files here are included by Sphinx wrapper pages or
kept as concise GitHub-readable references.

Start with:

- `../README.md` for installation and a quick local start.
- `user/quickstart.rst` for the first workflow.
- `guides/configuration.md` for configuration fields and environment overrides.
- `api/tools.md` for tool payloads.
- `operator/central_deployment.md` for shared Streamable HTTP deployments.
- `operator/security_checklist.md` before exposing a central service.
